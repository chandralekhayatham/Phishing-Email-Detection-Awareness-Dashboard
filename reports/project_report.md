# Phishing Email Detection & Awareness Dashboard

## Abstract
A defensive educational dashboard that analyzes synthetic email samples for phishing indicators, generates an explainable risk score, stores safe analysis metadata, and teaches users practical phishing-awareness habits.

## Scope
Sender, subject/body, URL, and attachment filename analysis; rule-based scoring; optional TF-IDF + Logistic Regression; dashboard/history; awareness lessons.

## Limitations
Project thresholds are assumptions and require calibration on authorized validation data. No single indicator proves phishing. ML results depend on dataset quality.
